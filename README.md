# Erica Okoro Portfolio

A futuristic personal portfolio website built with HTML, CSS, and JavaScript. The design uses a neon cosmic aesthetic, animated star background, and a subtle 3D Three.js element to create a modern showcase for projects, skills, and contact information.

## Overview

This project is a single-page portfolio for a full-stack developer, featuring:

- A cinematic hero section with a glowing introduction
- Smooth scrolling navigation between sections
- A featured projects gallery
- An about section highlighting technical skills
- A contact form for inquiries
- Animated space-inspired backgrounds and visual effects

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Three.js
- Google Fonts

## Features

- Responsive layout for desktop and mobile viewing
- Custom neon purple theme inspired by space and cyber aesthetics
- Animated starfield background and glowing UI accents
- 3D torus knot animation rendered with Three.js
- Clear portfolio storytelling for projects and personal brand

## Run Locally

Because this is a static site, you can view it immediately by opening `index.html` in your browser.

For a better local preview, run a simple local server:

```bash
cd "C:\Users\phoen\OneDrive\Documents\projects\portfolio 2"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

To personalize this portfolio:

- Update the name and title in `index.html`
- Replace project cards with real portfolio items
- Add your own social links and contact details
- Adjust colors, fonts, and animations in `style.css`
- If needed, connect the contact form to a backend or email service
